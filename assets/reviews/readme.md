# Customer photos go here

Name each file to match the `image` path set in `js/reviews.js`, e.g.:

```
customer-1.jpg
customer-2.jpg
customer-3.jpg
```

Until a file exists at the path a review points to, that card automatically
shows a set of initials instead — nothing breaks, and nothing else needs to
change. Square images (at least 100×100px) work best.
