# Team photos go here

Name each file to match the `image` path set in `js/team.js`, e.g.:

```
finn.jpg
rudransh.jpg
```

Until a file exists at the path a team member points to, that avatar
automatically shows their initials instead — nothing breaks, and nothing
else needs to change. Square images (at least 100×100px) work best,
since they're cropped into a circle.
